## 💫 About Me

🔩 I don't do tutorial projects. If I build something, it needs to be real enough to defend in front of an examiner — or in front of a senior engineer. That's my bar.

📦 My biggest project so far is **CleanHome** — a full Django marketplace for cleaning services, complete with service listings, bookings, and user roles. Built it, shipped it, then had to explain every design decision in a viva. 10/10 would stress again.

🤖 Right now I'm going deep into **ML Engineering** — not just training models, but building pipelines that detect drift, version themselves, and don't fall apart in production. Scikit-learn, Flask/FastAPI, the works.

🔧 **Currently building:**  
Self-monitoring ML systems — drift detection, ensemble methods, model versioning, all served via REST APIs.

📚 **Currently learning:**  
How production ML actually works beyond the Jupyter notebook. DSA on the side because it never goes away.

❓ **Ask me about:**  
Django internals, ML pipeline design, how to make academic projects actually defensible, or what not to put on a CS resume.

🎯 **Goal:**  
Build a portfolio where every project has a reason to exist — not just lines on a README.
